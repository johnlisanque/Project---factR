# Getting started

this gude explains how to setup projectFactR in Local development

# 1. Before starting to code
before working on projectFactR. you must install the following
 - Git
 - visual studio or any IDE
 thats it. you are now ready to code

# 2. clone the repo
Clone the repository using Git:

```bash
git clone https://github.com/johnlisanque/Project---factR.git
``` 
# 3. open the project 
navigate into the project
```bash
cd Project---factR
```
# 4. before editing
 - check git status
 - sync changes to avoid conflict
